Configuración Webfleet GPS
Conexión a WEBFLEET.connect API para obtener KM en tiempo real
⚪
Sin configurar
Ingresa las credenciales y presiona "Probar conexión"
🔑 Credenciales WEBFLEET.connect
⚡ Configuración Power Automate
1. Crea un Flujo de Nube instantáneo con trigger HTTP request (cuando se recibe una solicitud HTTP)
2. Agrega paso HTTP → GET → https://csv.webfleet.com/extern?account=@{triggerBody()?['account']}&username=@{triggerBody()?['username']}&password=@{triggerBody()?['password']}&apikey=@{triggerBody()?['apikey']}&action=showObjectReportExtern&outputformat=json&lang=es
3. Agrega paso Respuesta → Body: @{body('HTTP')} · Status: 200 · Header: Access-Control-Allow-Origin: *
4. Copia la URL del trigger y pégala abajo
⚠️ El modo directo puede ser bloqueado por CORS desde el navegador. Se usará proxy externo (corsproxy.io) como respaldo.
Credenciales Webfleet
ℹ️ Las credenciales se almacenan solo en tu navegador (localStorage). Usa Account + Username + Password + API Key de tu cuenta WEBFLEET.connect.
